    Validators

    Validators in the committee are tracked from their own block signatures; nothing to install. Names and heartbeats come from operators who registered. Heartbeats matter most outside the committee, where a validator signs nothing.

    Put your name on your validator

    One transaction from a small separate wallet. You need Node.js 18 or newer and a little test ASE for fees. Your validator shows up in the list either way; this only adds the name.

    1. Get the tool

      git clone https://github.com/<owner>/asentum-status
cd asentum-status && npm ci --omit=dev

    2. Create a wallet for it

      A new wallet just for this, never your validator key.

      npm run hb -- keygen

    3. Fund it

      Send it 0.1 test ASE. At today's fee of 1 wei per gas, that lasts for years.

    4. Register the name

      npm run hb -- register my-node --validator ase1… --no-heartbeat

    Add a heartbeat

    Worth it if your validator is outside the committee, or if you want to know that your node accepts and relays transactions. Register with --interval 300 instead of --no-heartbeat (or switch later with update --interval 300), then start the systemd timer described in the README.
