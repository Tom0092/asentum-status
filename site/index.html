    Operators

    Each operator's node sends a small heartbeat transaction every few minutes. If the network is fine but one heartbeat stops, that node has a problem.

    Add your node

    About ten minutes on the machine that runs your validator. You need Node.js 18 or newer and a little test ASE for fees.

    1. Get the sender

      git clone https://github.com/<owner>/asentum-status
cd asentum-status && npm ci --omit=dev

    2. Create a heartbeat wallet

      Use a new wallet just for heartbeats, never your validator key.

      npm run hb -- keygen

    3. Fund it

      Send it 0.1 test ASE. At today's fee of 1 wei per gas, that covers years of heartbeats.

    4. Register your node

      npm run hb -- register my-node --interval 300 --validator ase1…

    5. Start the timer

      The repository has a systemd service and timer that send one heartbeat every five minutes. The README has the details.
